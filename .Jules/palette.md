## 2024-05-14 - Dynamic ARIA Labels in Vanilla JS Templates
**Learning:** Adding ARIA labels to dynamically rendered interactive elements in vanilla JS is essential for accessibility. Because the HTML structure is built using string template literals (e.g., `renderList`), hardcoding generic ARIA labels like "Increase quantity" removes important context for screen readers. Using string interpolation (`aria-label="Aumentar cantidad de ${item.name}"`) ensures the screen reader provides precise, actionable descriptions that change according to the specific item being interacted with.
**Action:** When adding ARIA labels to vanilla JS string templates, explicitly use dynamic variable interpolation (`${variable}`) rather than static labels to ensure clear context for screen-reader users, especially for list or cart items.
