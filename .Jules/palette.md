## 2025-02-23 - Dynamic ARIA Attributes in Vanilla JS Templates
**Learning:** When injecting ARIA attributes (like `aria-label` or `aria-live`) into dynamically generated Vanilla JS content via template literals, it is essential to patch the string interpolation logic directly within the DOM-generating functions instead of attempting post-render `querySelector` updates, as the latter is brittle. Also, `aria-live="polite"` should be applied directly to the span whose inner text changes (e.g. quantity counter) for screen readers to accurately announce the change without focus shift.
**Action:** Always inspect JS template literals for icon-only buttons (`+`, `-`, `×`) and dynamic text (quantity) and add appropriate ARIA attributes there, using variables (e.g., `aria-label="Agregar ${product.name}"`) to provide context.
