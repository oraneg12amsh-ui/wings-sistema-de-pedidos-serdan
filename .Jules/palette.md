## 2026-04-02 - Dynamic ARIA Labeling in Single-Page Vanilla JS Apps
**Learning:** In vanilla JS apps generating HTML via template literals (like `renderList`), a11y must be injected dynamically into the string interpolations (`aria-label="Aumentar cantidad de ${item.name}"`), and state changes like quantity updates should utilize `aria-live="polite"` on the parent container instead of relying entirely on focus management. Also, string extraction methods need to account for extremely long unformatted JS lines when analyzing code structure.
**Action:** When auditing vanilla JS codebases, use `sed` or `fold` to bypass truncation limits on `grep`/`cat`, verify dynamic element structure fully before suggesting a11y fixes, and always ensure dynamic updates use `aria-live` or contextual ARIA labels based on data models.
