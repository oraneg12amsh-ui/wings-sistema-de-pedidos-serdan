## 2024-06-25 - Dynamic ARIA Labels in E-Commerce Flows
**Learning:** In e-commerce apps like this one, many interactive components (like "Add to Cart" or quantity adjuster buttons) are injected dynamically via JavaScript template strings. Screen readers lack context for these generic icon buttons (`+`, `-`, `x`) if they are only labeled visually by adjacent DOM elements. Static analysis often misses missing ARIA labels inside JS strings.
**Action:** When auditing or implementing accessibility improvements, always explicitly search for UI components rendered via template literals (e.g., inside `.innerHTML` assignments) and interpolate dynamic variables into `aria-label` attributes (e.g., `aria-label="Agregar ${product.name} al carrito"`) to provide specific, contextual labels for screen reader users.
