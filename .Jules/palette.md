## 2024-05-14 - Dynamic Template String ARIA Labels
**Learning:** When evaluating accessibility in Vanilla JS applications, static HTML analysis is insufficient. Many interactive elements (like cart quantity controls or add-to-cart buttons) are generated dynamically via template literals. Furthermore, these dynamic labels must utilize template variable interpolation (e.g., `aria-label="Disminuir cantidad de ${item.name}"`) to provide contextually accurate announcements for screen readers, preventing ambiguity when multiple similar buttons exist in a list.
**Action:** Always inspect JavaScript template strings (`.innerHTML = \`<button...\``) for missing `aria-label`s on icon-only interactive elements, and use variable interpolation to guarantee label uniqueness and context.
