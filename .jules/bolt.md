## 2024-03-26 - Vanilla JS List Rendering Optimization
**Learning:** This single-file vanilla JS application heavily relies on dynamic DOM generation for lists (products, cart items, admin items). Because it lacks a virtual DOM (like React/Vue), appending elements one by one in a loop (e.g., `dom.productList.appendChild(card)` inside `filtered.forEach`) triggers layout reflows and repaints for every single item, creating a measurable bottleneck when rendering large lists like the 30+ products.
**Action:** Always batch DOM insertions in vanilla JS codebases using `DocumentFragment`. Create the fragment outside the loop, append items to it inside the loop, and then append the fragment to the live DOM once. This reduces the DOM interactions to O(1) instead of O(N) per render cycle.
