## 2024-04-15 - DocumentFragment for Batched DOM Insertions\n**Learning:** In highly dynamic Vanilla JS applications, iteratively appending elements to the DOM within loops (e.g., rendering long product lists or cart items) causes continuous layout thrashing and repaints, severely degrading rendering performance.\n**Action:** Always utilize `document.createDocumentFragment()` to accumulate DOM nodes in memory during loop iterations, and perform a single `appendChild()` to the live DOM afterward.
