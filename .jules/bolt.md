## 2024-04-25 - Redundant Iterator Elimination in Order Totals
**Learning:** Performing multiple separate `.reduce()` calls on the cart array for large datasets causes unneeded performance overhead. Memory instructions indicate that a single `for` loop implemented in `getCartTotals` is approximately 10x faster for calculating properties like subtotal and count in large datasets. Additionally, redundant calculation logic exists across multiple functions (`renderCart`, `updateTotals`, `updateCambio`, order submission).
**Action:** Always centralize multiple related array aggregation calculations into a single `for` loop helper function (e.g., `getCartTotals()`) and pass its result object (`precalculatedTotals`) around where possible, rather than executing multiple individual array methods.
