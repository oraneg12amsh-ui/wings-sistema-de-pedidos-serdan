## 2025-02-18 - Optimized redundant `.reduce` cart iterations
**Learning:** Avoid centralizing isolated `.reduce()` calculations in `index.html` into a single universal function (e.g., `getCartTotals()`). While a single loop seems faster, it causes frequent, lightweight operations like `renderCart()` (which only needs an item count) to redundantly calculate expensive, unrelated totals (like discounts and shipping), degrading overall performance. However, for a DRY (Don't Repeat Yourself) cleanup, consolidating `reduce()` iterations makes the code much more readable and maintainable.
**Action:** When working on application state loops requiring multiple aggregated values, replace multiple distinct array iteration functions (like `reduce`, `map`, `filter`) with a centralized single `for` loop to clean up the code.
