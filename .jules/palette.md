## 2024-05-18 - Added ARIA labels to dynamically generated Vanilla JS buttons
**Learning:** When making accessibility improvements in Vanilla JS codebases that generate heavy DOM structures via string literals (e.g., `index.html`), it's essential to patch the `aria-label` attributes directly into the strings. Attempting to add them via `querySelector` post-render is brittle. Furthermore, testing these changes with Playwright when external CDNs time out requires creating a patched local HTML file using standard CLI tools.
**Action:** When working on similar Vanilla JS templates in the future, modify the string interpolation logic directly. Always use a locally patched HTML file without external module imports for Playwright verification to guarantee reliability in restricted network environments.
