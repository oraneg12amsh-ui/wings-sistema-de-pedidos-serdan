## 2024-05-24 - Screen Reader Accessibility for Icon-only Interactive Controls
**Learning:** In the `index.html` file, many interactive controls like the mobile cart button (`#mobile-cart-button`), modal close buttons (`#close-extras-modal-button`, `#admin-close-panel`), and dynamically rendered quantity adjusters (`.increase-qty-btn`, `.decrease-qty-btn`) relied exclusively on generic icons (`svg`) or symbols (`&times;`, `+`, `-`) with no visible text or ARIA context. This creates a severe barrier for screen reader users who rely on non-visual semantic descriptions to navigate and understand the purpose of interactive elements. Adding descriptive, translated `aria-label` attributes (e.g., "Abrir carrito", "Cerrar modal") makes these controls inclusive and completely understandable via assistive technology.

**Action:** Whenever introducing new icon-only buttons or symbol-based controls, always ensure a descriptive `aria-label` attribute is included in the HTML definition. This is especially important for dynamically generated UI elements where ARIA attributes must be included in the template literals (e.g., within `renderList`).
