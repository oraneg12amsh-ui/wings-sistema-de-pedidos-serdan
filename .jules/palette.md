## 2024-05-06 - Form Accessibility Improvements
**Learning:** In highly customized, Tailwind-styled Vanilla JS applications, developers often wrap inputs in `<div>` elements with descriptive `<label>` tags for visual presentation but forget to programmatically link them using `for` and `id` attributes. Additionally, single-input elements like search bars and specific login modals often rely entirely on placeholder text without providing accessible labels.
**Action:** When auditing custom form implementations, always verify the explicit linkage between `<label>` and `<input>`/`<select>`/`<textarea>`. Use `for` matching the `id` for grouped inputs, and use `aria-label` for standalone inputs (like search bars or specific admin fields) where a visual label would clutter the design.
